Entry for the [make.fun bounty "The Best Advice I Ever Got"](https://make.fun/bounty/u-pangg7-the-best-advice-i-ever-got-358cefb0).

`main.py` (Python 3.13, stdlib only, no network) writes one sentence — at most
200 characters — about the best advice the writer ever received, to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` by default). It is
deterministic: every run writes the same bytes.

Run it:

```sh
python3 main.py
```
